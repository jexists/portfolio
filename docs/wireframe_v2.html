보는 법
  • 첫 화면의 자동완성에서 직무를 고르면 그 직무 렌즈로 검색결과가 열립니다. 고르지 않으면 실제 사이트에서는 "정주애"로 자동 진행합니다.
  • 검색 이후 화면은 네이버 인물정보 카드 형태입니다. 카드 안의 둥근 탭으로 전체 / 경력사항 / 프로젝트 / 기술스택·자격 / 학력·교육 / 기타를 바꿉니다.
  • 검색창 아래 "연관 검색어"가 직무 렌즈입니다. 누르면 검색어, 헤드라인, 대표 미디어, 강조 순서, 자주 묻는 질문 순서, 이력서 PDF가 바뀝니다.
  • 모바일에서는 오른쪽 열(자주 묻는 질문, 바로가기)이 인물정보 카드 아래로 내려가고, 탭과 연관 검색어는 가로로 스크롤됩니다.
